## What a restart loses and how to rebuild it (everything below is git-ignored)

Assume `data/`, `third_party/`, `H-JEPA/` and the conda env may be gone. Order:

1. Env + H-JEPA + AntMaze data: `RESTORE.md`, or `scripts/runs_2026-11-27/restore_core.ps1` (needs H-JEPA cloned at
   97054ec with `hjepa_changes/hjepa_modified_files.patch` applied; see RESTORE.md). Git may not be on PATH:
   use `"C:\Program Files\Git\cmd\git.exe"`. Set `HJEPA_HOME=<repo>\data`, `HOME=%USERPROFILE%`, `PYTHONUTF8=1`.
2. Kitchen packages: `python -m pip install gymnasium-robotics==1.4.2` (minari 0.6.0 was already in the env).
3. Kitchen data (~1 min): `python experiments/kitchen/inspect_minari.py` (downloads D4RL/kitchen complete, partial,
   mixed into `data/minari`).
4. Frames (~2 min, 4 GB): `python experiments/kitchen/render_dataset.py --workers 8` → `data/kitchen/frames256/`.
5. V-JEPA 2.1 code + weights (4.8 GB):
   `git clone --depth 1 https://github.com/facebookresearch/vjepa2.git third_party/vjepa2` (used commit 204698b) and
   download `https://dl.fbaipublicfiles.com/vjepa2/vjepa2_1_vitl_dist_vitG_384.pt` to `data/vjepa2/`.
6. Encode (~20 min): `python experiments/kitchen/encode_vjepa.py` → `data/kitchen/vjepa21L_256/`.
7. Readout: `python experiments/kitchen/readout.py`.

AntMaze extras rebuilt on 27 Nov (only if needed again): `data/macro_actions_ant_l3_h5.npz`, `data/z3_game_assets.pt`,
RGM models copied from `checkpoints/system2/*.pt` and `checkpoints/rgm/*.pkl` into `data/` (incl.
`rgm_paper_z3_k64_seed42.pkl`).
