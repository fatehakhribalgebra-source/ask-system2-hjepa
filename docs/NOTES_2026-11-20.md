## What the RGM is (system2/rgm_paper.py)

The Pong/Breakout agent of the RGM paper, with the game frame replaced by H-JEPA's level-3 latent z3 (one step = 20
env steps):
1. **Perception up.** z3 -> 32-d PCA whitening -> nearest of 64 k-means states (level 1). Level 2 / level 3 items
   are runs of 2 / 4 consecutive states with counted transitions (temporal renormalisation; structure learning by
   counting unique events, no gradients). Built from 1,250 real episodes in ~4 s per seed.
2. **Inductive planning at the top** (`spm_induction`): transitions thresholded at 1/16 of the best successor, goal
   items = items containing a goal state (`spm_set_goals`), backward propagation <= 16 steps.
3. **Prediction down, no action list.** The predicted next observation is the REAL exemplar latent (data medoid) of
   the next distinct state on the plan.
4. **Reflex = H-JEPA below.** The prediction is passed to level 2 as the plan to follow, as `[now, target, target]`
   so that H-JEPA's last-subgoal anchoring cannot replace it with the goal image. Levels 2 and 1 make it happen.
5. **Commitment by temporal depth.** The plan is held for one top-level item (4 latent steps) while reality matches
   it; otherwise induction runs again from the real state. In a goal state it hands over to H-JEPA's own planner.

Offline (held-out episodes): plans found 124-125/125 per seed, plans end ~0.5 maze units from the goal's true xy.

## The road there (all on tasks 0-12, seed 42; `results/l3_planner_pc2/summary_A.md` has every table)

| Approach | Best | Lesson |
|---|---|---|
| RGM as level-3 *action* planner (12 macro-action prototypes), replan every call | 10/13 | works, coarse actions |
| ... commit to route, replan on drift | 9/13 | routes too short (1/16 threshold = "possible", not "likely") |
| ... EFE commit-or-replan (adaptive) | 3/13 | looks only forward; loops on moves reality refuses |
| ... two realities: F3-checked routes + surprise from reality (feedback) | 5/13, 8/13 with learning | F3's long imagined routes exaggerate; reality looks surprising |
| ... bridge: closed loop + learning + RGM/F3 product of experts, precision learned from reality | 10/13, mean 215 steps | best action planner; learning rate 10 |
| **Paper-style RGM on z3 (predict the next place, H-JEPA acts)** | **13/13, 13/13, 11/13** | the decisive change |
| ... with continual learning (lr 10) | 9/13 | offline counts already a good attracting set |
| ... on z2 (reflex = level 1 only) | 5/13 | z2 exemplars carry pose; level-1 cost is flat |

Key facts learned:
- Single runs are NOT deterministic on this GPU (same seed, different outcomes). Always repeat.
- H-JEPA level 3 is only consulted for the first 270 of 350 env steps (horizon schedule decays to 1).
- F3 one-step predictions of the real next state are better than RGM's counts (log-lik -0.51 vs -0.72), but long F3
  rollouts drift.
- H-JEPA anchors the last subgoal of a plan to the true goal: an external planner must not put its target last.
