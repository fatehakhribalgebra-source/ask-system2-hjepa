## Findings (what is true now)

1. **Most of the 20 Nov losses were run-to-run noise.** On the 12 tasks the 76.0 planner lost at least once, a re-run of
   the same planner solved 10/12 (`results/rgm_screen/base`).
2. **Failures are timeouts while routing.** Of the 36 failed runs at 76.0, only 3 ever reached the goal state; the
   finishing phase after reaching it costs ~0 steps. Median solved run: 200 steps routing a ~6.4-latent-step (~130
   env step) plan (`experiments/rgm_time_budget.py`).
3. **Bug in the paper-style induction threshold: lingering states are dead ends.** The 1/16 rule compares every exit
   with the self-transition; where the ant lingers, all exits fall below 1/16 and the state has no way out (15 of 64
   states per k-means model; tasks 33/36 stuck in state 4, task 1 seed 44 in state 46). Fix (`Level.ignore_self`,
   opt-in): exits compete only with exits -> 5–8 dead ends. **F3 one-step imagined transitions remove the rest**:
   no-route start/goal pairs 11.6% -> 1.3% (seed 42), 7.3% -> 0.7% (seed 44).
4. **F3 is a good one-step transition source**: with the true macro-action, F3's snapped next state equals the real
   one 72–74% of the time when the state changes (0% for "stay"); 95% of imagined latents fit a state
   (`experiments/build_f3_transitions.py`).
5. **Aliasing is not out-of-distribution latents**: live z3 fit their states like training z3 (0–1.4% beyond the
   training 99.5% quantile). A few states simply cover distant places (state 24, seed 42: 12 maze units).
6. **e-means (Bessa et al. 2026, `--cluster emeans`)**: 8–12% lower held-out MSE, no near-empty states, fewer dead ends
   (5.1% no-route vs 7–12% for k-means), same offline plan quality. Aliasing unchanged.
7. **Online learning on top of an offline map is a drop in the bucket**: ~7 accepted counts per task vs 23,750 offline;
   carried across 12 tasks = 0.35% of the map (`experiments/learning_amount.py`).

## What was built (all opt-in; defaults reproduce the 20 Nov planner)

- `system2/rgm_full.py` — filtering through mu(B), MI-gated continual learning, imagined transitions.
- `system2/rgm_agent.py` — RGMAgent: + Bayesian refusal of failed moves (dwell-time model comparison), surprise as
  precision (hand over), EFE fallback, live F3 first-hop ranking, e-means states, F3 transitions, `--rgm-persist`.
- `system2/rgm_live.py` — **LiveRGM: no offline map.** States grown on the fly (radius = one F3 step, no data),
  exemplar = the real z3 that created the state, goal gets its own state, counts at 1/2/4 steps from real play, F3
  one-step dreaming with random macro-actions on the LayerNorm action manifold, refusal = failures since the last
  success, EFE fallback, else H-JEPA acts (and its trip is learned). **Dreaming** (`--rgm-dream`): at each task start
  the RGM does its "offline" structure learning on F3 rollouts (6 steps, drift guard) from every real state + now +
  goal; imagined states become real when visited.
  - Stream test (`experiments/test_rgm_live.py`, recordings only as a stand-in for live play, same radius):
    routes for 50 unseen start/goal pairs after 2 episodes: **43/50 with dreams vs 0/50 without**; 49 vs 38 after 25.
  - Sim smoke (seed 42, tasks 0–5, empty start, `results/rgm_live_smoke/dream`): plans from task 0; 3/6 solved;
    **many failed hops** (4–13 per task) — likely states too large (radius = one full F3 step) and/or dreamed edges
    through walls. Next to try: `rho` 0.5.
- Tools: `eval_rgm_offline.py`, `test_rgm_agent.py`, `compare_runs.py`, `learning_amount.py`, `trace_rgm_runs.py`,
  `rgm_time_budget.py`, `run_rgm_screen.ps1` (variants: base, obs10, agent, agentp, live, dream, ...).
