## Key finding: the curious play map hardly plans

The 24 Nov "13/13 on tasks 0-12" with the curious play map came mostly from H-JEPA's own planner. The RGM decided
only 17% of the time; the rest were "no path" handovers. That map is fragmented:

| Map (K=64) | Largest strongly connected set | Reachable state pairs |
|---|---|---|
| curious play | 18/64 | 23% |
| random play | 62/64 | 97% |
| offline dataset | 56/64 | 88% |
| curious play, auto K=128 | 25/128 | - |

The likely cause is that curious play stays local, and the explore episodes start from the eval tasks' start states.

## Ideas to carry forward

- **Fragmentation is the play-map problem.** Options: explore from new places (not the task starts), a
  curiosity bonus for reaching unconnected components, the risk planner using F3-imagined bridges, or random play
  mixed into curious play.
- **Actions as outcomes.** An upper-level action is "go to that state" (a displacement in the level below), so its
  space is the set of places reachable from here: a per-state vocabulary, not one fixed manifold.
- **Counterfactual hops** (Counterfactual WM): estimate an untried hop from a tried one, ẑ(a′) = z′ + μ(z,a′) − μ(z,a).
- **Adapt the reflex at test time** (AdaJEPA, JEPA-TTT, OpTTA): a few gradient steps on H-JEPA's prediction loss
  during the life. Smooth latents (SVReg) would make clusters into places more reliably.
